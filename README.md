# ERFVII-PCO-coevolution
Reproducible pipeline to identify ERF-VII and PCO homologs across a curated set of plant species, validate canonical domain architectures, and generate QC-ready datasets for downstream phylogenetic and coevolution analyses.

### Project goal
This project aims to evaluate coevolutionary patterns between ERF-VII transcription factors and Plant Cysteine Oxidases (PCOs) across ~90 plant species. The current repository focuses on: 
- homology search at the protein and gene (nucleotide) levels using HMMER
- canonical domain identification and dataset curation.
